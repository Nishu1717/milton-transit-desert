# Data Sources

Download and place the following files in this folder before running analysis.py

1. Milton Transit GTFS
   - stops.txt
   - stop_times.txt
   - Source: https://www.miltontransit.ca

2. Ontario Municipal Boundary shapefile
   - Source: https://geohub.lio.gov.on.ca

3. Statistics Canada 2021 Census Profile CSV - Ontario only
   - Source: https://www12.statcan.gc.ca
